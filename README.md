## 🚀 Fitur Presentasi Web
* **Neo-Brutalist & Canva Digitalism Design:** Tata letak kartu interaktif dengan efek bayangan tegas (*hard shadows*), *traffic lights* browser, dan *progress bar* dinamis.
* **Foto Dokumentasi Asli:** Dokumentasi resmi wawancara mendalam bersama **Kepala Laboratorium (W1)** di Bengkel IT JTIK FT UNM pada 6 Oktober 2026.
* **Crop Layar Penuh (Fullscreen):** Menekan tombol **⛶ Layar Penuh** atau tombol **F** akan memfokuskan tampilan hanya pada kotak slide tanpa elemen luar.
* **Fitur Edit Teks Langsung:** Tersedia tombol **✏️ Edit Teks** untuk mengedit teks secara langsung di browser dan menyimpannya.
* **Audio & Navigasi Keyboard:** Navigasi cepat dengan tombol panah (← / →), spasi, enter, dan efek suara klik.

## 🌐 Deploy di Cloudflare Pages
Situs web ini statis dan siap langsung di-*hosting* melalui Cloudflare Pages:
1. Hubungkan repository GitHub ini di **Cloudflare Dashboard ➔ Workers & Pages ➔ Create application ➔ Pages ➔ Connect to Git**.
2. Pilih repository ini (`si-sapras-jtik`).
3. Pengaturan Build:
   - **Framework preset:** `None`
   - **Build command:** *(Kosongkan)*
   - **Build output directory:** `.` atau `index.html` *(Root directory)*
4. Klik **Save and Deploy**. Website langsung aktif di domain `https://<nama-proyek>.pages.dev`!
